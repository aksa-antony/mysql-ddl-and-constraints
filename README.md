# MySQL DDL and Constraints

## Overview
This project demonstrates the use of MySQL Data Definition Language (DDL) commands and database constraints using an employee database.

## SQL Concepts Practiced
- Creating databases and tables
- ALTER TABLE
- Adding, modifying, and dropping columns
- Renaming columns and tables
- TRUNCATE and DROP
- PRIMARY KEY
- NOT NULL
- UNIQUE
- AUTO_INCREMENT
- CHECK
- DEFAULT
- FOREIGN KEY

## Database Tables
- Employees
- Departments
- Location
